**Value proposition**: The marketplace's thesis is IDEA → ROADMAP → PLAN → build → ship, yet its own
development ships off-board. The entire context-routing initiative (PRs #269–#281) — an RFC (#269) and
12 implementing PRs, 13 merged in all — created no EPIC, no PLAN, and no board linkage. Nothing enforced it: the documented GIT
WORKFLOW omits the board, and no gate checks linkage. This EPIC closes the gap so substantive work is
captured on the board first and every PR is traceable to a board item — without overburdening trivial
fixes (`muri`).

**Brief**: Four reinforcing guardrails, calibrated **require-with-logged-exemption**:
1. a **board-first step** in the documented workflow + a shared **linkage convention** (0066.001);
2. a **deterministic pre-push gate** `verify-board-linkage.sh` that fails a PR with no linked board
   item, honouring a logged `[no-board]: <reason>` exemption (0066.002);
3. a **planning-time tripwire** that steers substantive work onto the board before it is built (0066.003);
4. a **PR template + CI backstop** (0066.004).

The guardrails catch the gap at three moments — plan time (tripwire), push time (gate), and review time
(template/CI) — because Slice 5 failed at *plan* time, so a merge-only gate would just block finished work.

## Shared infrastructure
- **The linkage convention** — the single source of truth every other PLAN reads: a `Board: #<issue>`
  (or `Refs #<issue>`) commit/PR trailer naming an EPIC/PLAN issue on project #4, **or** a
  `pipeline/NNNN-*` branch name, **or** a `[no-board]: <reason>` logged exemption for trivial work. **Owned by PLAN 0066.001** (defines it in
  CLAUDE.md); 0066.002 (gate), 0066.003 (tripwire), and 0066.004 (template/CI) all consume it. Build
  0066.001 first — 0066.002/003/004 depend on it.
- **`docs/roadmap/`** — established by 0066.001 (it does not exist today); holds the on-disk EPIC/PLAN
  build-instruction docs, with the GitHub Project board remaining authoritative for *state*.
