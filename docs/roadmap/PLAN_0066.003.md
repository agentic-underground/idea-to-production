**Brief**: Catch the gap at the moment it opened — *planning time*. A SessionStart-injected reminder (the
best-effort steering pattern the context-routing tripwire already uses) that substantive/multi-PR work
starts with `/deliver:roadmapper` (board item first), so a merge-time gate never has to block finished
work.

## User stories
- AS the builder entering a substantive task I WANT a reminder to capture it on the board first SO THAT I
  don't discover the linkage requirement only at push time.

## EARS specification
- **EARS-001** (Event-driven) — WHEN a session starts in this repo, the hook SHALL inject a concise
  board-first reminder naming `/deliver:roadmapper` and the linkage convention.
- **EARS-002** (Ubiquitous) — the reminder SHALL be advisory (best-effort steering, not a hard block) —
  the deterministic block is PLAN 0066.002's gate; this is the early nudge.
- **EARS-003** (Unwanted) — IF the work is trivial, THEN the reminder SHALL point at the `[no-board]`
  exemption rather than demanding an EPIC/PLAN.

## Acceptance criteria
1. Given a new session in this repo, When SessionStart runs, Then the injected context names the
   board-first step, `/deliver:roadmapper`, and the exemption.
2. Given the hook, When inspected, Then it writes only advisory context (no repo mutation, no failure).

## Human interface test plan
None — a SessionStart hook. Proof: run the hook script and assert its stdout contains the board-first
reminder + the convention; assert it exits 0 and writes nothing to the repo.

## Implementation notes
- Model on the existing i2p SessionStart injection hooks (`plugins/*/hooks/`) — a small script that
  echoes advisory context. Repo-scoped (only in this marketplace repo), idempotent, zero-token.
- Keep it short (one or two sentences) so it doesn't crowd the context — the same discipline the KAIZEN
  injection follows.
- Optionally a plan-mode note (a CLAUDE.md line already covered by 0066.001) reinforces it.

## Construction process
Author the hook + a tiny test asserting its output + inertness; wire it into the repo's hook config; PR
linked to this issue; `/deliver:pr-review` (SECURITY for the hook — it injects context, so confirm it
mutates nothing and reads no untrusted input); self-merge on PASS.

## Definition of done
- SessionStart reminder fires in this repo, advisory-only, zero repo mutation.
- Test asserts output + inertness; `.pipeline/verify` GREEN; adversarial review PASS.
